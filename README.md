# BARRIO21

BARRIO21 es un prototipo funcional de e-commerce frontend enfocado en ropa urbana, streetwear y sneakers.

El proyecto fue desarrollado con HTML, CSS y JavaScript puro, con una interfaz adaptable para computadoras, tablets y celulares.

## Funcionalidades

- Catálogo dinámico de 24 productos.
- Búsqueda por nombre, tipo y color.
- Filtros por categoría.
- Ordenamiento de productos.
- Sistema de favoritos.
- Página individual para cada producto.
- Selección de talla y cantidad.
- Carrito lateral de compras.
- Modificación y eliminación de productos.
- Persistencia del carrito mediante localStorage.
- Formulario de checkout.
- Selección de método de pago demostrativo.
- Confirmación y generación de número de pedido.
- Diseño responsive para dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome
- Google Fonts
- Live Server

## Páginas principales

- `index.html`: página de inicio.
- `tienda.html`: catálogo completo.
- `producto.html`: detalle de producto.
- `checkout.html`: resumen y confirmación del pedido.

## Ejecución local

1. Descargar o clonar el proyecto.
2. Abrir la carpeta en Visual Studio Code.
3. Instalar la extensión Live Server.
4. Abrir `index.html` con Live Server.

## Tipo de proyecto

Este proyecto es una demostración frontend. No procesa pagos reales y no utiliza todavía un backend o una base de datos.
